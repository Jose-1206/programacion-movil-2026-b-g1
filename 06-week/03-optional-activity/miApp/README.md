# Mi Primera App Ionic React

## Descripción

Proyecto inicial desarrollado con Ionic React como práctica de instalación del entorno móvil.

## Tecnologías utilizadas

- Node.js LTS
- Ionic CLI
- React
- TypeScript

## Instalación del entorno

Primero se instaló Node.js en su versión LTS.

Después se instaló Ionic CLI mediante:

npm install -g @ionic/cli

## Creación del proyecto

El proyecto fue creado utilizando:

ionic start miApp blank --type=react

## Ejecución

Para ejecutar la aplicación se utilizó:

ionic serve

La aplicación fue ejecutada correctamente en el navegador.

## Modificación realizada

Se modificó el título inicial de la aplicación y se agregó un mensaje de bienvenida.
