
# Week 11 — Attendance Control UX/UI Workshop

## Project overview

Attendance Control is a system for managing class attendance through QR codes.

The project includes student and professor roles, course management, class sessions, QR-based attendance registration, and attendance history.

This workshop focuses on improving the student experience, especially when reviewing attendance records and accessing class information.

## Baseline

The team currently has a Java Spring Boot backend but does not have an available Ionic React frontend.

For this reason, the official Ionic React course starter is used as the initial baseline, as permitted by the workshop instructions.

The starter has been copied without functional modifications. The following checkpoints will progressively introduce the attendance-related UI.

## UX/UI focus

The main goal is to make attendance information easier to understand and navigate.

The planned improvements will focus on loading and error feedback, navigation consistency, accessibility, and responsive layouts.
